# Xquik Monitoring

Portable skill for turning Xquik X data into compact monitoring handoffs.

Use it for launch checks, competitor watchlists, keyword monitoring, and audience-signal summaries when the next agent needs source links and a short verified state rather than a raw timeline.

Public references:

- `https://xquik.com/openapi.json`
- `https://xquik.com/.well-known/mcp.json`
- `https://docs.xquik.com`

Keep Xquik credentials in environment variables, connectors, or secret stores. Do not put them in handoffs or public docs.
